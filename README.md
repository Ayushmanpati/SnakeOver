# SnakeOver

A real-time hand gesture controlled Snake game built using Computer Vision and Machine Learning techniques.

## 🔧 Tech Stack
- Python 3.11
- MediaPipe Tasks API
- OpenCV
- Pygame

## 🎮 Features
- Hand gesture based snake control
- EMA smoothing to reduce jitter
- Dead-zone and hysteresis for stable movement
- Wall bounce logic
- Real-time score counter
